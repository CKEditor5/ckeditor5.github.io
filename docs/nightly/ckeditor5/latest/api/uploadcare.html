Uploadcare integration for CKEditor 5

This package implements the Uploadcare integration for CKEditor 5. It allows you to update images directly from various services (like Dropbox, Google Drive, OneDrive) to CKEditor 5 content. Further, it allows editing images with multiple ready-to-use functions, like crop, rotate, applying various filters, changing brightness, contrast, saturation, and similar.

This feature is useful for easily allowing advanced image integration with editor.
