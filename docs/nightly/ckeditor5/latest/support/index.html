Getting support

Contribute to this guideShow the table of contents

Commercial support

Copy link

As a licensed customer, you benefit from direct support from the core CKEditor 5 development team. Our commercial licenses are tailored for professionals and enterprises. If you have any support requests, please contact us.

For more information, check the CKEditor 5 Pricing page.

Asking questions

Copy link

If you have questions about our products or features:

  • If you are a customer or your questions relate to our premium features, please contact us.
  • If you have questions about the integration steps or best practices, you can submit an issue. Please note that our response may take some time. Thank you for your understanding.

Reporting issues

Copy link

If you believe you have found an issue in CKEditor 5, we appreciate you letting us know. Before creating a bug report, please read the guidelines on how to do it properly and efficiently.

Reproduce on official examples

Copy link

To eliminate the possibility that the issue is caused by third-party software or your customizations, first try to reproduce the issue on the official examples.

The examples are always running the latest editor version. Please note that if the problem was fixed in a release newer than the version you are using, you will need to upgrade your CKEditor 5 installation as we do not backport fixes.

Most issues are reproducible on the demo. If your case is different, follow the steps described below.

Submitting an issue

Copy link

If you are a commercial customer, please reach us via our support channel for the fastest response.

We keep most of our issues on GitHub to provide open access to reported cases. To report a new issue, you will need a GitHub account.

Issues should be reported via the specific issue trackers:

  • CKEditor 5 repository.
  • Angular integration,
  • React integration,
  • Vue integration,
  • CKEditor 5 inspector.

Things to keep in mind:

  • Search for existing issues before starting a new one. This helps our team keep the backlog organized.
  • Be concise and informative to make it easy for our team to understand the problem.
  • Feel free to join discussions around issues and share your opinion!

Issues with third-party plugins should be reported directly to their developers.

Reporting security issues

Copy link

If you believe you have found a security issue in the CKEditor 5 software, please contact us immediately.

When reporting a suspected security problem, please bear this in mind:

  • Make sure to provide as many details as possible about the vulnerability.
  • Please do not disclose publicly any security issues until we fix them and publish security releases.

Contact the security team at security@cksource.com. As soon as we receive the security report, we will work promptly to confirm the issue and provide a security fix.
