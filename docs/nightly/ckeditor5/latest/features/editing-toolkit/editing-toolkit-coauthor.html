Coauthor (CKEditor MCP)

Show the table of contents

Coauthor is the backend part of the Editing Toolkit. It lets AI agents read and edit CKEditor 5 documents on the server through the Model Context Protocol (MCP), without anyone having the document open in a browser. Your agents connect to its MCP server to apply direct edits or Track Changes suggestions. Backend code can also call the same tools over REST without using an AI model. With real-time collaboration, people can keep editing the same document while agents work.

Available in early access

Contact us to enable Coauthor in your trial or existing environment. We will help you with the server-side setup.

Contact us View plans

Why a server-side editor

Copy link

A backend agent drafts a report from your application’s data. A second agent reads it and leaves comments on the sections a person should check. The reviewer opens the document in CKEditor 5 and starts from those comments.

Coauthor lets both agents work on the same document in a server-side CKEditor 5 instance, without anyone having it open in a browser. Agents can check their output against the editor’s features and configuration and use the feedback to revise it before applying it. An editor retains only the HTML its features support, so unsupported markup can be lost during import.

The server-side editor runs the same editor bundle that you upload to Cloud Services, so it has the same features, plugins, and configuration as the editor your users see.

What agents get

Copy link

Coauthor exposes three things to an agent:

  • Skills available through MCP tools describe how the editor works and which features the document supports. They help agents produce HTML the editor accepts.
  • Tools available through MCP and REST let agents and backend code read, edit, and verify document content and add comments.
  • A server-side CKEditor 5 instance uses Compare to apply direct edits or Track Changes suggestions. These changes work with real-time collaboration, comments, and revision history.

When to use Coauthor

Copy link
  • Run agents that draft, review, and edit documents without an open browser editor. For example, one agent writes a first draft and a second one checks it. See the backend agent workflows guide.
  • Let users start document editing tasks in an app such as Claude or ChatGPT and review the results in CKEditor 5. See the agent apps guide.
  • Build your own AI features. Coauthor helps your agent produce content the editor accepts, and Compare presents the result for review in the browser. See the custom chat implementation guide.

Setup

Copy link

Coauthor works with and without real-time collaboration. With real-time collaboration, document storage follows your collaboration setup. Otherwise, your integration determines how Coauthor loads and saves documents, as described in Document types.

Contact us to enable Coauthor during early access. Then follow the Coauthor guides in the Cloud Services documentation:

  • Quick start – Connect Claude Code and a small agent of your own to a trial environment.
  • Set up your environment – Add DocumentCompare to your editor bundle and find the MCP address.
  • Authentication – Sign the tokens for your backend and your agent.
  • API reference – Find every endpoint, tool, and error of Coauthor.

Availability

Copy link

Coauthor is part of the Editing Toolkit and is in early access. It is not enabled in the free trial by default. Contact us to join the early access program and enable Coauthor in your trial or existing environment. General availability is planned for the first quarter of 2027.
