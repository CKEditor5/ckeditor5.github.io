AI Assistant (legacy)

Show the table of contents
Important

AI Assistant is now a legacy feature: maintained for existing customers, but no longer actively developed.

CKEditor AI is a separate product with a much broader feature set, including a more advanced interface, dedicated interactions, MCP support, programmatic control, and much more. It is available as a Cloud (SaaS) or on-premises deployment.

AI Assistant provides a way to boost your editing efficiency and creativity through the use of AI (“artificial intelligence”) capabilities. Users can generate new content and process the data using custom queries, or choose an action from the predefined list of commands, which you can also configure to your liking.

UI colors

Copy link

The AI Assistant user interface follows the CKEditor 5 editor theme, so it blends in with the rest of the editor out of the box. Earlier versions gave it a distinctive violet tint that set AI-powered actions apart from other features. The tint is gone, and the interface now takes its colors from whichever theme you use.

If your integration needs the AI Assistant to stand out, you can apply custom colors to its user interface, including bringing back the violet tint.

Integration

Copy link

AI Assistant relies on an external service to provide AI-generated responses. You will need to have access to such a service.

The feature supports integration with AI API providers: OpenAI and Azure OpenAI. You can also integrate it with custom models.

Read the AI Assistant integration guide to learn more.

Customization

Copy link

You can customize the feature to better fit your needs, for example:

  • Change the list of the predefined commands by adding new ones or removing existing ones.
  • Change the UI colors, styling, and sizes.

Read the AI Assistant configuration and styling guide to learn more.

Data filtering in responses

Copy link

The AI response will only incorporate HTML elements and features that are compatible with the editor. For instance, if an AI Assistant response contains <b>Bold text</b>, your editor needs the Bold plugin to be loaded to preserve it.

Note

See the overview of the plugins’ HTML output to learn which features you need. You can also use the General HTML Support feature to insert custom HTML into the content.

Query history

Copy link

The AI Assistant’s custom query field has a dedicated history button that gives you access to your previous queries. It displays the last 20 queries and makes it possible to reuse and improve recent queries. The history is stored in the browser’s session storage. The session storage is separate for each browser tab and the browser clears it when you close the tab.

A user can also manually clear the query history by clicking the “Clear” button in the history dropdown.

Known issues and caveats

Copy link

Integration with some features

The AI Assistant feature will be inactive if the current selection contains one of the following elements: media embed, HTML embed, or table of contents.

You can overwrite the list of features where the AI Assistant is inactive by changing the config.ai.assistant.disabledElements configuration property.

Comments and suggestions

When the AI model processes the selected content, it removes all markers. This means all comments and suggestions will be removed in the AI response.

Broken images in the responses

The AI model, if asked directly, may return image elements linking to non-existing images, which will appear broken in the response and in the editor content after being inserted.

Integration with custom features

Due to the nature of the technology behind this feature, you may get unexpected results when processing content that includes custom features that you have developed.

The AI model will try to process the HTML data according to how it was trained. However, if your feature creates a complex HTML structure or custom HTML tags, there is a higher chance that these will not be processed correctly.

If you experience problems with your custom features, you might turn off AI Assistant when they are selected by changing the config.ai.assistant.disabledElements configuration property.

Common API

Copy link

The AIAssistantUI plugin registers:

  • The 'aiCommands' UI dropdown component.
  • The 'aiAssistant' UI button component.
  • The 'showAIAssistant' command.

You can execute the command to display the AI Assistant:

editor.execute( 'showAIAssistant' );
Copy code

You can also display the AI Assistant and automatically submit the query to the AI service:

editor.execute( 'showAIAssistant', 'The query sent to the AI service', 'Label to display in the query field' );
Copy code

We recommend using the official CKEditor 5 inspector for development and debugging. It will give you tons of useful information about the state of the editor such as internal data structures, selection, commands, and many more.
