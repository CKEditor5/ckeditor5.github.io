AI Quick Actions

AI Quick Actions streamline routine content transformations by offering one-click AI-powered suggestions directly within the editor. You can also ask questions about your selected text in the Chat to get instant AI insights and analysis. This feature enhances speed, relevance, and usability, particularly for repeatable or simple tasks. The feature comes with an easy-to-use window interface but can also act as a conversation starter with the Chat.

Integration

Copy link

To start using the Quick actions feature, first load the AIQuickActions plugin in your editor configuration. Learn more about installing and enabling AI features.

Then, you can add the menu that opens the list of Quick actions ('aiQuickActions') to your main toolbar and/or balloon toolbar configurations. To learn more about toolbar configuration, refer to the toolbar configuration guide.

Finally, you can also add individual Quick actions to the toolbar as shortcuts for even easier access. For example, you can add the 'ask-ai' button, or the 'improve-writing' button (find it in the demo above). You can add whole categories to the toolbar, too. Learn more about available actions.

The final example configuration looks as follows:

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			/* ... */
		},

		// Adding Quick action to the main editor toolbar.
		toolbar: [
			// The main Quick actions button
			'aiQuickActions',

			// Two individual actions
			'ask-ai',
			'improve-writing',

			// Whole action category
			'translate',

			/* ... */
		],

		// Adding Quick Actions to the balloon toolbar. Since some of the actions are selection-sensitive,
		// accessing them might be easier for users using this kind of toolbar.
		balloonToolbar: {
			items: [
				// The main Quick actions button
				'aiQuickActions',

				// Two individual actions
				'ask-ai',
				'improve-writing',

				// Whole action category
				'translate',

				/* ... */
			],
		}
	} )
	.then( /* ... */ )
	.catch( /* ... */ );

Types of actions

Copy link

There are two types of actions available in the Quick actions feature:

  • Some actions, for instance, “Ask AI” or “Summarize”, lead to the Chat interface with selected text added as context. The former will just open the Chat and allow you to start typing your message. The latter, however, will not only open the Chat but also start the conversation for your current editor selection right away, and expect a summary of that selection from the AI.

  • Executing other actions like “Continue writing” or “Make shorter” will open the window interface conveniently right next to your selection and present the answers from the AI for you to accept or reject them.

You can define the behavior of each action when you create custom ones.

Resizing the balloon

Copy link

By default, the balloon’s width automatically matches the width of your editing area, up to 900px, and its height is fixed. Declare the following CSS custom properties to set the size yourself instead:

:root {
	--ck-ai-actions-balloon-width: 800px;
	--ck-ai-actions-balloon-height: 400px;
}
Copy code

Declaring --ck-ai-actions-balloon-width takes precedence over the automatic width and its 900px limit, so the balloon stays at the width you set regardless of the editing area’s size.

Default actions

Copy link

By default, the Quick actions feature includes several built-in actions that speed up the content editing process. All Quick actions can be accessed through the menu button ('aiQuickActions') but also individually when handpicked by the integrator in the editor toolbar configuration. You can add the whole action categories to the toolbar too.

Keep in mind that you can add custom actions to the list, remove defaults, and arrange the actions.

Here’s the full list of available actions:

  • 'ask-ai',
  • “Chat commands” category ('chat-commands')
    • 'explain',
    • 'summarize',
    • 'highlight-key-points',
  • 'improve-writing',
  • 'continue',
  • 'fix-grammar',
  • “Adjust length” category ('adjust-length')
    • 'make-shorter',
    • 'make-longer',
  • “Change tone” category ('change-tone')
    • 'make-tone-casual',
    • 'make-tone-direct',
    • 'make-tone-friendly',
    • 'make-tone-confident',
    • 'make-tone-professional',
  • “Translate” category ('translate')
    • 'translate-to-english',
    • 'translate-to-chinese',
    • 'translate-to-spanish',
    • 'translate-to-german',

    • 'translate-to-italian',
    • 'translate-to-russian',

Custom actions

Copy link

The config.ai.quickActions.extraCommands property allows you to add new commands to the AI Quick Actions feature. Below, you will find an example of three extra actions added to the user interface: two of them open the quick actions window, but the last one interacts with the Chat. Learn more about types of actions.

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			quickActions: {
				extraCommands: [
					{
						id: 'add-quote-from-famous-person',
						label: 'Add a quote from a famous person',
						prompt: 'Add a quote from a known person, which would make sense in the context of the selected text.',
						type: 'action'
						// No `model` specified — uses the default configured in `ai.models.defaultModelId`.
					},
					{
						id: 'summarize-in-bullet-points',
						label: 'Summarize',
						displayedPrompt: 'Summarize in 5 bullet points',
						prompt: 'Summarize the selected text in 5 bullet points.',
						type: 'chat'
					},
					{
						id: 'include-more-sarcasm',
						label: 'Rewrite adding more sarcasm',
						prompt: 'Rewrite using a sarcastic tone.',
						type: 'action',
						model: 'claude-4-6-sonnet' // Pin a specific model for this action.
					}

					// ... More commands ...
				],
			},

			/* ... */
		}
	} )
	.then( ... )
	.catch( ... );
Copy code

An action can also take its prompt from a context instead of carrying it inline. See the Context section below.

Categories and icons of custom actions

Copy link

By default, the editor adds custom actions at the end of the “Other” category. Use the group property to add an action at the end of another category instead. It can be a default category, for example 'translate', or a new category that you define in config.ai.quickActions.items. If the category does not exist, the editor adds the action to the “Other” category and logs a warning in the console.

Use the icon property to give an action its own icon as an SVG string. The editor shows the icon when you add the action to a toolbar or place it at the top level of the Quick actions menu. Without it, the action uses the icon of its category.

ai: {
	quickActions: {
		extraCommands: [
			{
				id: 'translate-to-polish',
				label: 'Polish',
				prompt: 'Translate the selected text to Polish.',
				type: 'action',
				// The last action in the "Translate" category.
				group: 'translate'
			},
			{
				id: 'rewrite-for-brand',
				label: 'Rewrite for our brand',
				prompt: 'Rewrite the selected text in a friendly, concise brand voice.',
				type: 'action',
				icon: '<svg viewBox="0 0 20 20" xmlns="http://www.w3.org/2000/svg">...</svg>'
			}
		]
	}
}
Copy code

The placement in config.ai.quickActions.items takes precedence over group:

  • If you list the action in items yourself, the menu shows it where you list it.
  • If you define its category in items with its own list of actions without the action, the menu does not show the action. You can still add the action to a toolbar by its id.
  • If you leave its category out of items, the menu does not show the category or the action. You can still add both to a toolbar, and the category includes the action.

To remove an action completely, use removeCommands.

To add custom actions to a new category, define the category in items without its own list of actions. The category then collects every custom action that names it in group. The menu shows only the entries that you list in items, so list the default actions and categories that you want to keep, too:

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			quickActions: {
				extraCommands: [
					{
						id: 'add-emoji',
						label: 'Add emoji',
						prompt: 'Add fitting emoji to the selected text.',
						type: 'action',
						group: 'extras'
					}
				],
				items: [
					// The default actions and categories, in their default order.
					'ask-ai',
					'chat-commands',
					'improve-writing',
					'continue',
					'fix-grammar',
					'adjust-length',
					'change-tone',
					'translate',

					// The new category. It collects the custom actions with `group: 'extras'`.
					{
						id: 'extras',
						label: 'Extras',
						icon: '<svg viewBox="0 0 20 20" xmlns="http://www.w3.org/2000/svg">...</svg>'
					},

					'other'
				]
			},

			/* ... */
		}
	} )
	.then( /* ... */ )
	.catch( /* ... */ );

Removing default actions

Copy link

The config.ai.quickActions.removeCommands property allows you to remove existing commands from the AI Quick Actions feature. It accepts action IDs only, not category IDs. To remove a whole category, list all its actions. Here’s an example that removes two actions (”Explain” and “Summarize”):

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			quickActions: {
				removeCommands: [
					'explain',
					'summarize',

					// ... More commands to remove ...
				]
			},

			/* ... */
		}
	} )
	.then( ... )
	.catch( ... );

Arranging actions

Copy link

The config.ai.quickActions.items property sets the order and placement of the actions and categories in the Quick actions menu and in the menu bar. If you do not set it, the menu shows the default actions in their default order, with the custom actions in the “Other” category.

Each entry in items is one of the following. You can find the IDs of the default actions and categories in the Default actions section.

  • The ID of an action, for example 'fix-grammar'. It can be a default or a custom action, including one that belongs to a category by default. The menu shows the action at the top level.
  • The ID of a category, for example 'translate'. The menu shows the category with its default actions, except for the actions that you placed elsewhere in items.
  • A category definition – an object with the following properties:
    • id – The ID of a default category or a new one.
    • label – The label of the category. Defaults to the label of the default category or to the id.
    • icon – The icon of the category as an SVG string. Defaults to the icon of the default category or to a generic icon.
    • items – The IDs of the actions in the category, in display order. Defaults to the actions of the default category. For a new category, defaults to the custom actions that name it in group.

The example below moves a custom action to the top, changes the order of the default actions, keeps three languages in the “Translate” category, and creates a new “Length and tone” category:

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			quickActions: {
				extraCommands: [
					{
						id: 'rewrite-for-brand',
						label: 'Rewrite for our brand',
						prompt: 'Rewrite the selected text in a friendly, concise brand voice.',
						type: 'action'
					},
					{
						id: 'add-quote-from-famous-person',
						label: 'Add a quote from a famous person',
						prompt: 'Add a quote from a known person, which would make sense in the context of the selected text.',
						type: 'action'
					}
				],
				items: [
					// A custom action at the top level of the menu.
					'rewrite-for-brand',
					'ask-ai',
					'fix-grammar',
					'improve-writing',

					// A default category with three of its actions.
					{
						id: 'translate',
						items: [ 'translate-to-english', 'translate-to-german', 'translate-to-french' ]
					},

					// A new category with actions from two default categories.
					{
						id: 'length-and-tone',
						label: 'Length and tone',
						icon: '<svg viewBox="0 0 20 20" xmlns="http://www.w3.org/2000/svg">...</svg>',
						items: [ 'make-shorter', 'make-longer', 'make-tone-casual', 'make-tone-professional' ]
					},

					'chat-commands',

					// Collects the custom actions that you did not place anywhere else: "Add a quote from a famous person".
					'other'
				]
			},

			/* ... */
		}
	} )
	.then( /* ... */ )
	.catch( /* ... */ );
Copy code

Keep in mind the following rules:

  • The Quick actions menu and the menu bar show only the entries that you list in items. The actions that you leave out are still available as toolbar items, for example 'continue' in the example above. To remove an action completely, use removeCommands.
  • A category that you leave out is still available as a toolbar item with the actions that you did not place elsewhere. If you place all of its actions elsewhere, the category is no longer available, for example 'adjust-length' in the example above.
  • List the 'other' category to show the custom actions that you did not place anywhere else.
  • The editor shows every action and category only once. If you list one more than once, it uses the first entry. It also skips a category definition that uses the ID of an action.
  • You cannot nest categories. The editor skips a category that you list in the items of another category.
  • You can add a new category to the toolbar by its id, just like a default one. Category and custom action IDs share the toolbar item names with other features, so use names that are not taken, for example not 'undo' or 'link'. If a name is taken, the editor keeps the toolbar item of the other feature and logs a warning in the console.
  • An action that you move to another category belongs to it. The window of the action shows the label of the new category in its title, except for the “Other” category, and the default context matches the ID of the new category. An action that you place at the top level does not belong to any category, so the default context of its previous category no longer applies to it.
  • The editor logs a warning in the console for every entry that it cannot use: an unknown ID, a duplicate, or a nested category.

Context

Copy link

Quick actions can draw on a context from the Context Library – a named container of reusable prompts, reference files, or both, kept on the AI service and referenced by its id. A context can shape every action automatically, or supply the prompt of a single custom action.

Default context

Copy link

Reference the context in config.ai.defaultContext and target the quickActions feature. Set it to true to attach the context to every action:

ClassicEditor
	.create( {
		/* ... */

		plugins: [ AIQuickActions, /* ... */ ],

		ai: {
			defaultContext: [
				{
					id: 'brand-voice',
					features: {
						quickActions: true
					}
				}
			]
		}
	} )
	.then( /* ... */ )
	.catch( /* ... */ );
Copy code

Provide a RegExp instead to attach the context only to selected actions. It is matched against the ID of the action and the ID of the group it belongs to, so a group ID covers every action inside it. The example below attaches a glossary to the whole “Translate” category, which includes translate-to-german and its siblings:

ai: {
	defaultContext: [
		{
			id: 'glossary',
			features: {
				quickActions: /^translate/
			}
		}
	]
}
Copy code

Both the default actions and the custom ones are covered. The attached context is invisible to the user. When an action of the 'chat' type starts an AI Chat conversation, that conversation receives the matching quickActions entries as well as the chat entries.

Prompt from a context

Copy link

An action of the 'action' type can take a context reference instead of an inline prompt, so the prompt is maintained in the Context Library rather than in the editor configuration. This suits instructions owned outside the codebase – the team that owns the brand voice updates the prompt in the library, and every custom action picks it up without a deployment. The prompt text also stays out of the frontend: it is not stored in the editor configuration and does not show up in the network traffic of the request. Combining both sends the inline prompt and attaches the context as reference material:

ai: {
	quickActions: {
		extraCommands: [
			// The referenced prompt drives the action.
			{
				id: 'rewrite-for-brand',
				label: 'Rewrite for our brand',
				type: 'action',
				context: { id: 'brand-voice', promptId: 'bR8xY_2fLpQ4mZ7nK1sTd' }
			},

			// An inline prompt with a file attached as reference material.
			{
				id: 'add-quote-from-famous-person',
				label: 'Add a quote from a famous person',
				type: 'action',
				prompt: 'Add a quote from a known person, which would make sense in the context of the selected text.',
				context: { id: 'brand-voice', fileId: 'Xh3TpQ9-rNs6BvL2mKd0W' }
			}
		]
	}
}
Copy code

A context that references only a single file cannot drive an action on its own and must be combined with an inline prompt. An action of the 'chat' type has no context property and always carries its prompt inline, but it still receives the default context entries that match it.

Note

The promptId and fileId values are generated by the AI service, unlike the context id. Read more about context references.

Quick Actions can be triggered programmatically – execute system actions or custom prompts from code.

Experimental

Some of our APIs are experimental but ready for production usage. We mark them as experimental to have a possibility to iterate on them faster. That means minor releases without the standard deprecation policy. Breaking changes will always be documented in the changelog with migration guidance.
