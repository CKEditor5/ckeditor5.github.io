Using file managers

Contribute to this guideShow the table of contents

The most convenient way to upload, manage, and insert images into content in CKEditor is by using file managers. CKBox and CKFinder are our official file managers and file uploaders that let you upload, manage, and insert images and other files.

Note

CKBox and CKFinder are both premium features. Contact us to receive an offer tailored to your needs.

CKBox file manager

Copy link

CKBox is a modern file management platform with a clean UI and a top-notch UX.

With CKBox you can:

  • Organize images and other files into customizable categories.
  • Create, rename, and delete folders.
  • Delete, rename, and tag files.
  • Search files and filter results by numerous properties.
  • Easily access recently used files.
  • View images in high-resolution full-page preview.
  • Define and reuse alternative text for images.
  • Get your images served quickly through global AWS S3 CDN or via local options, such as filesystem or SQL databases.

Read the dedicated CKBox feature guide to learn about its installation and configuration. The guide also lets you try CKBox in action.

Uploadcare file manager

Copy link

Uploadcare is a modern file management platform with multiple integrations with services like Dropbox, Google Drive, Google Photos and OneDrive.

With Uploadcare you can:

  • Upload images directly from:
    • Dropbox,
    • Google Drive,
    • Google Photos,
    • OneDrive,
    • Local computer,
    • External URL.
  • Manage all uploaded images through a dedicated platform.
  • Edit images by changing dimensions, applying filters and adjusting various image parameters.
  • Get your images served quickly through global AWS S3 CDN.

Read the dedicated Uploadcare feature guide to learn about its installation and configuration. The guide also lets you try Uploadcare in action.

CKFinder file manager

Copy link

CKFinder is a powerful file manager with various image editing and image upload options.

With CKFinder you can:

  • Group images and other files into folders and subfolders.
  • Move or copy files between folders.
  • Easily filter files.
  • Drag and drop images and paste them from the clipboard into the editor.
  • Crop, rotate, edit, and resize images.

Read the dedicated CKFinder feature guide to learn about its installation and configuration. The guide also lets you try CKFinder in action.
